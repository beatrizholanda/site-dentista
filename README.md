# 🌸 Website — Dra. Waleska Caetano

Este é o código-fonte do site **institucional da dentista Waleska Caetano**, desenvolvido em **HTML, CSS e JavaScript**.  
O objetivo do projeto é apresentar os **serviços odontológicos**, **informações profissionais** e **formas de contato** de maneira moderna, clara e responsiva.

---

## 🦷 Demonstração

💻 **Página principal:** destaca os principais serviços, um banner de destaque e um carrossel com resultados de clareamento dental.  
📸 **Seções:**  
- **Banner:** mensagem principal com botão de agendamento.  
- **Serviços:** tratamentos de canal e clareamento dentário.  
- **Carrossel:** comparação de “antes e depois”.  
- **Perfil:** sobre a dentista e link para a página “Sobre”.  
- **Rodapé:** informações de contato e navegação adicional.
